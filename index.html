运行说明

推荐运行方式（本地服务器）：
由于浏览器安全策略，直接双击 index.html 打开时，fetch 加载本地 JSON 可能被拦截。 建议在项目根目录启动一个本地静态服务器：
  • Python：python -m http.server 8000，然后访问 http://localhost:8000
  • Node.js：npx serve 或 npx http-server
  • VS Code：安装 Live Server 插件后右键 index.html → Open with Live Server
直接打开也能用：本项目内置了兜底数据，即使 fetch 失败，页面仍可正常展示数据（控制台会有黄色警告，属正常现象）。
错误处理：网络断开、数据为空、数据格式错误时，页面会显示明确的中文提示，不会白屏或卡死。可在 Console 中查看详细错误信息。
技术栈：HTML5 + CSS3 + JavaScript（ES6）+ Bootstrap 5 + jQuery + ECharts + Chart.js + Three.js。数据基于本地 JSON。
